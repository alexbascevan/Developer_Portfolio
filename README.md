## ✨ Features

### 🎯 Core Features
- **Light & Dark Mode**: Toggle between light and dark themes with persistent user preference
- **Custom Cursor**: Dynamic, personalized cursor effect (desktop only) with smooth trail animations
- **Smooth Animations**: Sophisticated intersection animations with fade, blur, and scale effects
- **Responsive Design**: Fully responsive across all devices (mobile, tablet, desktop)
- **Grid Layout**: Professional grid overlay background for visual appeal
- **Performance Optimized**: Built with Vite for fast build times and optimal performance
- **Contact Form**: Email contact form powered by Formspree with real-time validation and success notifications

### 🎨 Visual Effects
- **Section Transitions**: Smooth fade-in/fade-out animations as you scroll
- **Project Cards**: Advanced card animations with staggered entrance effects
- **Interactive Icons**: Social links with theme-aware colors and smooth hover effects
- **Typography Animation**: Typewriter effect on the hero section

### 🔧 Developer Features
- **Centralized Data**: All content loaded from data files for easy maintenance
- **Reusable Components**: Modular component architecture for scalability
- **CSS Variables**: Theme-based CSS variables for consistent styling
- **ESLint Integration**: Code quality checks built-in

## 📈 Performance Features

- **Lazy Loading**: Intersection Observer API for efficient animations
- **Optimized Bundle**: Vite provides tree-shaking and code splitting
- **CSS Variables**: Lightweight theme switching without CSS duplication
- **Will-change**: GPU acceleration for smooth animations
